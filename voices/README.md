# Bundled voices

Each voice is three files: `<name>.pt` (the saved `VoiceClonePrompt`, which also stores the
reference transcript), `<name>.wav` (the reference clip it was cloned from) and `<name>.json`
(the voice record: `language`, `locale`, `gender`, `label`, `multilingual`, `ref_text`,
`description`). The catalog was assembled by `migrate_catalog.py` from the 2026-11-03 audition
(`audition/`).

None of these voices may be used commercially: the OmniVoice model weights are CC-BY-NC, and the
voice-bank clips are CC-BY-NC-SA 4.0.
